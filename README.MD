# Knights Travails

A JavaScript project that finds the shortest path a knight can take between two positions on an 8×8 chessboard.

## How It Works

The project uses **Breadth-First Search (BFS)** to explore possible knight moves and find the shortest route.

It uses:
- **Queue:** To manage positions waiting to be explored.
- **Set:** To keep track of visited positions.
- **Map:** To remember previous positions and reconstruct the shortest path.



## Technologies

- JavaScript
- Breadth-First Search (BFS)
- Data Structures: Queue, Set, Map

## What I Learned

- Graph traversal and BFS.
- Working with queues.
- Preventing repeated visits.
- Reconstructing paths using parent relationships.
